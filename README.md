PocketBI 📊

Lightweight Business Intelligence & Data Analytics — Right in Your Browser

PocketBI is a lightweight, mobile-friendly business intelligence tool that helps users turn raw data into meaningful insights without needing advanced technical skills or expensive analytics software.

Import a dataset, explore your data, generate visualizations, and identify useful patterns through a simple browser-based interface.

🚀 Why PocketBI?

Working with raw spreadsheets can be time-consuming, especially for students, small businesses, and beginners who may not have access to advanced analytics tools.

PocketBI aims to make data exploration easier by bringing essential analytics features into one simple web application. Instead of manually creating every chart or switching between multiple tools, users can upload a dataset and start exploring it in one place.

✨ Features

- 📁 Multiple File Formats: Import CSV, Excel (".xlsx", ".xls"), JSON, and TXT files.
- 📊 Automatic Dashboard: Generate visual summaries of your dataset.
- 📈 Interactive Charts: Explore data through visualizations.
- 🔎 Data Inspection: Review your dataset and examine its contents.
- 🎛️ Filters: Narrow down data to explore specific segments.
- 🧮 Formula Columns: Create calculated columns for additional analysis.
- 💬 Ask Your Data: Use rule-based queries to explore supported questions about your dataset.
- 💾 Saved Dashboards: Save and revisit dashboard configurations in your browser.
- 📋 Data Export and Copying: Copy data as CSV for use in other tools.
- 📱 Mobile-Friendly Interface: Work with data through a responsive interface designed for smaller screens as well as desktops.

📖 How to Use

1. Open PocketBI in your web browser.
2. Import a dataset using a supported file format.
3. Explore your data using the data inspection tools.
4. Review the dashboard and available visualizations.
5. Apply filters to focus on specific records or segments.
6. Create formula columns when you need additional calculated fields.
7. Use Ask Your Data to try supported, rule-based questions.
8. Save your dashboard to revisit it later in the same browser.
9. Copy or export data when you want to continue working in another tool.

Tip: Start with a clean, well-structured dataset with clear column headers for a smoother experience.

⚙️ Technical Notes and Limitations

- PocketBI runs in the browser; it does not currently require a custom backend.
- Imported data and saved dashboard information are stored locally in the browser where supported.
- Data is not automatically synchronized between devices or browsers.
- Clearing browser storage may remove locally saved information.
- The current application has a dataset limit of up to 50,000 rows.
- External libraries and fonts are loaded from CDNs, so an internet connection is needed for the complete experience.
- Ask Your Data is rule-based, not a full AI-powered natural-language analytics system.
- Browser memory and device performance may affect how smoothly large datasets work.
- Avoid using sensitive or confidential data unless you have reviewed the application's data handling and storage behavior.

🔒 Privacy

PocketBI is designed to process data in the browser rather than through a dedicated PocketBI backend. However, it loads third-party resources from external CDNs, and its exact behavior depends on the deployed code and browser environment.

Review the source code before using sensitive data. Do not assume that browser-based storage is equivalent to encrypted or secure cloud storage.
